# Interactive-BMI-Calculator-Python

An interactive BMI calculator built with Python and `ipywidgets` in a Jupyter Notebook. Users can type or select their weight and height, calculate their BMI category, and view the approximate weight range associated with the healthy adult BMI category for their height.

## Features

- Interactive height and weight inputs.
- Linked widget controls for easier data entry.
- Input validation and clear error messages.
- Automatic BMI calculation.
- Classification using standard adult BMI categories.
- Suggested healthy weight range based on the selected height.
- Results displayed directly in the notebook.

## Tools Used

- Python
- Jupyter Notebook
- `ipywidgets`

## How to Use

1. Download or clone the repository.
2. Open the notebook in Jupyter Notebook or JupyterLab.
3. Install `ipywidgets` if it is not already installed:

   ```bash
   pip install ipywidgets

  Or using Anaconda Prompt:

  ```bash
  conda install ipywidgets
